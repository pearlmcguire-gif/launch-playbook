# Launch Playbook: from handoff to first results

An interactive page showing how I run software implementations ("launches") for small and medium businesses, from the Sales handoff to the first measured results.

**View it:** https://pearlmcguire-gif.github.io/launch-playbook/

## What's inside

- **Four short stories:** two hands-on builds, a hesitant client who switched platforms, and teaching a client.
- **A six-stage launch journey**, with the moment each stage's owner is likely to hesitate and what I'd say.
- **How I'd run a full launch load:** a weekly rhythm, one home per customer, and what I'd automate first with Claude.
- **A Launch board** with adjustable score weights and a "This week, first" list ranking which shops need time.

## Notes

- All companies, people and figures on the Launch board are fictional. Client stories are anonymized.
- Scoring criteria and guides are not part of this demo.
- Built with Claude. Uses PostHog, without cookies, to count which parts get used.
